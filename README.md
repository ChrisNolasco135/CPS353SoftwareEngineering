# Software Engineering Project Starter Code

 Trial Division (Checking if \(n\) is Prime)
 The user will input a positive integer and the system will calculate if the number is prime. EX: An input of 59 will return true

 The multi-threaded implementation uses Executors.newFixedThreadPool() to execute ConceptualAPI computations concurrently.

Maximum thread count: 4

The thread pool limits the number of simultaneous computations to four threads.
